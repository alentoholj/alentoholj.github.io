About me

I'm a Cloud Solution Architect at Blum, part of the IT Cloud Operations & Services team. My job is to design the platforms other teams build on: secure, well-governed cloud environments on Azure and AWS, and a fast, repeatable and safe road from a developer's commit to production.

In practice that means codifying infrastructure with Terraform, building CI/CD pipelines with security and compliance built in rather than bolted on, and running containerized workloads on Kubernetes and OpenShift. I care about the things that don't show up in a demo: reliability, observability and cost efficiency.

My path started in systems engineering and data-center operations, which is where I learned how infrastructure actually behaves under pressure. That on-premises background helps me design hybrid environments that work end to end.

What I focus on

  • 🏗️Cloud architecture on Azure and AWS: landing zones, networking and governance
  • 📜Infrastructure as code with Terraform and AVM
  • 🔁CI/CD with GitLab, Azure DevOps and GitHub Actions
  • ☸️Containers and Kubernetes (AKS, EKS, OpenShift)
  • 🛡️Security, reliability and FinOps

Storage Platform NDA

AzureTerraformAzure DevOps
Challenge

A client needed cloud infrastructure for a storage platform made up of an API, a companion service, a web frontend and a mobile app, with a reliable path from code to production across several repositories.

What I did

Owned the Azure architecture end to end: designed the resource topology, codified the infrastructure in Terraform and built Azure DevOps pipelines covering build, test and release for the API, the companion service and the web frontend.

Result

Repeatable, fully automated deployments of the backend and web frontend, with infrastructure managed as code instead of manual setup.
